# 自定义节拍高亮（Custom Beat Highlight）

RPEN 模组 · API 1 · 版本 `1.1.0` · 测试于 `Re:PhiEdit Next 0.14.0`

给制谱时的网格参考线加上**分级高亮**与**自定义吸附**：在不改动原生网格与谱面数据的前提下，把各节拍细分用不同颜色标出来，并让音符/事件吸附到你选定的节拍型或原生细网格上。

Adds **tiered highlights** and **custom snapping** to the chart grid: without touching the native grid or chart data, each beat subdivision is drawn in its own colour, and notes/events can snap to your chosen beat patterns or the native fine grid.

> **默认仅整拍线开启**：启用后先只显示整拍线（基准），其余细分默认关闭，需在面板中按需开启。
>
> **Only the whole-beat line is on by default**: after enabling, only whole-beat lines show; turn on other subdivisions in the panel.

---

## 功能一览（Features）

### 横线（节拍细分 + 整拍 / Horizontal lines）
- 读取编辑器原生「横线」数值（`division`）作为基础网格，不重复绘制。
- 内置「整拍 1/1」层，**默认开启**：`#f2efe9`、1.8px、100%、实线，绘制在整数拍并置于最上层。
- 每个「节拍型」（beat pattern）是分数 `M/N`：**每拍均分 N 份、以 M 为步长**，位置 = `k·M/N`（k=1,2,…，只落在当前拍内）。
  - `1/4` → 1/4、2/4、3/4；`3/4` → 仅 3/4；`2/3` → 仅 2/3。
- 支持内置 8 档 + **自定义节奏型（分子/分母可编辑）**；每个节拍型可独立设置颜色/粗细/透明度/线型。
- 颜色点击后弹出 **2×5 取色浮层**：前 9 个预设色，最后一格「笔」按钮打开原生取色器自选。
- 同一位置被多个节拍型覆盖时，**步长更大（更粗）者优先**（如 1/2 覆盖 1/4）。
- 列表表头：**拍型 | 是否高亮 | 颜色 | 粗细 | 透明度 | 线型**，与数据行逐列对齐。

默认配色：

| 层级 | 颜色 | 透明度 |
|---|---|---|
| 整拍 1/1 | `#f2efe9` | 100% |
| 1/2 | `#ff4d4d` | 85% |
| 1/3 | `#38bdf8` | 75% |
| 1/4 | `#fbbf24` | 75% |
| 1/6 | `#a78bfa` | 60% |
| 1/8 | `#34d399` | 60% |
| 1/12 | `#fb7185` | 45% |
| 1/16 | `#22d3ee` | 30% |
| 1/24 | `#a3e635` | 30% |

自定义节奏型按顺序循环 `#f472b6`、`#2dd4bf`，80%、虚线。

### 竖线（音符 X 坐标 / Vertical lines）
- 仅在音符视图生效；以 `x=0` 为中心向两侧对称、每隔 M 根高亮一根（默认 M=2）。
- 中心线可单独强调。

### 吸附（高亮即吸附 / Snapping）
- 每个节拍型只有 **「高亮」** 一个开关：勾选即显示，并自动成为吸附候选。
- **吸附功能总开关**：默认开启。
- **吸附模式**：可拖动的分段开关（灰色凹槽 + 黄色滑块），二选一（默认「仅原生」）：
  - **仅高亮**：吸附到勾选了「高亮」的节拍型位置。
  - **仅原生**：吸附到原生 `1/division` 细网格。
- 作用于：音符点击放置、音符拖拽、事件拖拽、全局事件编辑。

### 快捷键（可按需改键 / Shortcuts）
- `M`：启用 / 停用高亮（总开关）。
- `N`：切换吸附模式（仅高亮 ↔ 仅原生）。
- 面板内总开关/吸附模式旁有**半透明快捷键徽标**：点击进入录制，按新键即改；也可在模组管理器里改。
- 按 `M` / `N` 时会弹出**状态提示**：高亮开/关、当前吸附状态、吸附模式等；高亮未开启时按 `N` 会提示先按 `M`。

### 界面（Interface）
- 顶部工具条「吸附」旁有「网格」按钮，打开设置面板。
- 面板宽度固定（450，窄屏自适应到屏宽）；默认/最小高度 **700**，最大高度为窗口高度；可拖动标题栏移动、拖**底部居中横条**调整高度，位置始终钳制在屏幕内。
- 「恢复默认」会同时重置配置、面板尺寸与位置。

## 安装 / 导入（Install / Import）

1. **`.rpenmod`**：交给编辑器「模组 → 导入」。
2. **`.zip`**：把文件清单内容打包成 zip（根目录必须有 `mod.json`），再导入。
3. **文件夹**：在「模组 → 导入」中选择整个 `beat-grid-guide` 文件夹。

导入后需主动勾选风险确认；**导入后仍是禁用状态**，请手动启用。

---

## 使用（Usage）

1. 启用后点击工具条「网格」按钮打开面板。
2. 打开 **「启用（总开关）」**（或按 `M`）。
3. 勾选 **「启用横线高亮」**，「整拍 1/1」默认已开；再按需开启细分。
4. 需要吸附：打开 **「吸附功能总开关」**，用分段开关选 **仅高亮 / 仅原生**（或按 `N` 切换）。
5. 添加自定义节奏型：填「分子 / 分母」（如 `3` / `4`）点「添加」。

首次启用模组时会自动弹出一次新手说明（总开关、横线/竖线区域、吸附功能总开关与模式、相邻节拍过近的提醒）。关闭后不再自动弹出。

之后可在 **模组管理器** 里点击 **「重看新手教程」** 再次查看。

## 设置项说明（Settings）

| 设置 | 含义 |
|---|---|
| 启用（总开关） | 模组总开关（快捷键默认 `M`） |
| 启用横线高亮 | 是否绘制节拍细分高亮线（整拍层同受此控制） |
| 节拍型 · 是否高亮 | 是否绘制该节拍型；勾选即同时作为吸附候选 |
| 节拍型 · 颜色/粗细/透明度/线型 | 该节拍型样式 |
| 自定义节奏型 | 分子/分母（N ≥ 2，1 ≤ M < N） |
| 启用竖线高亮 | 是否绘制竖线高亮 |
| 每隔 M 根高亮一根 | 竖线高亮周期，默认 2 |
| 中心线样式 | `x=0` 中心竖线的独立样式 |
| 吸附功能总开关 | 吸附功能总开关（默认开启） |
| 吸附模式 | 仅高亮 / 仅原生（快捷键默认 `N` 切换） |
| 输出诊断日志 | 在控制台打印挂接信息 |

## 兼容性（Compatibility）

- **测试版本**：`Re:PhiEdit Next 0.14.0`（API 1）。
- **不改动谱面**：不写入任何谱面字段；停用即还原。
- **联机**：高亮与吸附均为本地行为，不参与同步、不产生数据冲突。
- **多模组共存**：全部通过托管接口（`patch`/`dispose`/`on`/`commands`）挂接。
- **配置迁移**：旧存档自动补「整拍」层；新默认配色需点「恢复默认」或全新安装才生效。

## 故障排查（Troubleshooting）

- 点击「网格」无反应 / 高亮不出现：确认已启用、且「总开关」与对应轴已开启；勾选「输出诊断日志」看 `[beat-grid-guide] 诊断`。
- 吸附不生效：确认「吸附功能总开关」已开、且对应节拍型已勾选「高亮」（仅高亮模式）。
- 应急：管理器禁用；`Ctrl+Alt+Shift+F11` 全禁用；地址栏加 `?mods=off`；桌面版 `--mods-off`。
